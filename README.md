# Ximo Quickscan

AI-gedreven bedrijfsanalyse door Ximo Solutions.

## Twee routes
- **Zonder inventarisatie:** start vanuit een bedrijfsnaam, website en eigen voorkennis.
- **Met inventarisatie:** importeer een JSON-export uit Ximo Inventarisatie.

Beide routes gebruiken dezelfde werkruimte met bedrijfsprofiel, onderzoek, inzichten, kansen en briefing.

## Gegevens en privacy
- Geen centrale opslag van klantdossiers in de frontend.
- Lokaal automatisch bewaren in de browser (localStorage).
- JSON import/export om later verder te werken.
- PDF via de afdrukfunctie van de browser.
- Lokale gegevens kunnen worden gewist.
- Lokale browsergegevens en gedownloade dossiers zijn niet door deze applicatie versleuteld.

## Status
**Frontend-basis gereed; AI-onderzoeksbackend nog niet aangesloten.** Er vindt nog geen online AI-onderzoek plaats. De volgende stap is een beveiligde backend voor brononderzoek, AI-analyse en onderbouwde kansen. API-sleutels horen nooit in deze openbare repository of frontend.
